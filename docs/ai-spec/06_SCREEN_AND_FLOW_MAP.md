# Bachelor Point — Complete Screen and Flow Map

## Entry

Splash → Authentication → Onboarding → What do you want to do?
- Find a Mess
- Join existing mess
- Create Mess

## No mess

No Mess Home → Find / Create / Explore

## Create

Create Mess → Basic Info → Preferences → Quick Setup → Review → Mess Created → Mess Hub

## Discovery

Find Mess → Search/Filters → Mess Cards → Mess Detail → Rules/Reviews/Manager/Costs → Request Join

## Join

Request → Pending → Manager Review → Accepted/Declined → Rule Acknowledgement → Active

## Management

Mess Hub → Manager Control Center → Members / Requests / Invite / Settings / Vacancy / Constitution / Announcements / Roles / Voting

## Meals

Meals/Bazar → Today's Meals → History → Correction → Manager Review

## Bazar

Meals/Bazar → Bazar → New Entry or Scan → Pending → Approved

## Expenses

Quick Log → Expense → Approval → Ledger

## Accounting

Bills/Split → Personal Breakdown / Transactions / Balance / Payment / Settlement

## Closing

Open Cycle → Review → Resolve Pending → Finalize Meal Rate → Close → Closed Summary → Mess Fund/Deficit

## Governance

Constitution → Rule Change → Save+Notify or Vote

## Election

Manager Change → Candidates → Secret Vote → Result → Tie means another round

## Reviews

Eligible Member → Write Review → Anonymous Verified Review → Manager Reply

## Messaging

Mess Detail → Contact Request → Manager Accepts → Conversation

## To-Let

To-Let → Listing Detail → Contact Request

Manager: Post Seat → Preview → Publish → Manage → Edit/Pause/Share/Fill

## Exit

Member → Leave Request → Settlement → Leaving → Former

Historical records remain.
